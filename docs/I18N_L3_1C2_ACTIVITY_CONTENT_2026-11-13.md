# L3.1c.2 — Activity results, feed and chat history

Localizes archive search results/errors, activity feed, history groups, actions/accessibility titles, and relative timestamps with existing room_list.ago + Rails datetime.distance_in_words catalogs. Author-only notification previews remain body-free; authorized search results retain the body by design and preserve room ACL and message links. Search period/kind, read cursor and event read status are unchanged. Search result timestamp title uses unambiguous numeric YYYY-MM-DD HH:mm across locales instead of English month formatting. Translation-only fallback for missing DM labels. Controller error strings moved to UI catalogs. No JS/CSS, schema or data mutations. Pagination widget internals are deferred for separate audit.
