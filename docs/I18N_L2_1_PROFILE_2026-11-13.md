Date: 2026-11-13. Follows L1.1 Home commit 7af26ee.

## Scope
- All user-facing template strings on Devise account edit page localized in
  EN, RU, HY, ES: headings, form labels, hints, email confirmation text,
  visibility preference, notification guidance, destructive action and confirm.

  strings via Stimulus values; a text-safe `{{filename}}` placeholder is

  presence preference or irreversible delete semantics.
